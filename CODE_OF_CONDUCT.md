# Code of Conduct

## Our standard

Be respectful. Disagree about the code, not the person. Assume good faith
until it's clearly not warranted, and give feedback the way you'd want to
receive it.

The following are not acceptable, here or anywhere else this project is
discussed: harassment, personal attacks, discriminatory language or jokes,
publishing someone else's private information without consent, and sustained
disruption of discussion or review.

## Scope

This applies to every space the project uses — issues, pull requests,
discussions, commits, and any other channel where people interact as
contributors or maintainers.

## Enforcement

Report a problem by opening a GitHub issue if it's something that can be
public, or by contacting a maintainer directly (see the repository owner's
GitHub profile) if it isn't. Reports are handled at the maintainer's
discretion; possible outcomes range from a warning to a permanent ban from
the project's spaces, depending on severity and pattern.

Maintainers who don't follow or enforce this in good faith may themselves
face consequences, up to removal from the project.
